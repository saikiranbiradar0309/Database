# What is a DBMS?

DBMS stands for Database Management System.

In simple terms, a DBMS is software that helps us create, store, access, update, and manage data in a database.

Think of it this way:

- **Database** = Storage room
- **DBMS** = Manager who controls the storage room

## 📝 Example

Suppose a company has employee data:

| ID | Name | Salary |
|---|---|---|
| 101 | Rahul | ₹50,000 |
| 102 | Priya | ₹60,000 |

The database stores this information.

A DBMS allows applications and users to interact with that data.

```
        User / Application
                ↓
              DBMS
                ↓
            Database
                ↓
        Employee Data
```

## 🛠️ What does a DBMS do?

A DBMS allows you to:

- Create databases and tables
- Insert data
- Retrieve data using queries
- Update data
- Delete data
- Control who can access the data
- Maintain data security
- Handle multiple users accessing data
- Provide backup and recovery

## 🗂️ Examples of DBMS

Some popular DBMS software are:

- MySQL
- PostgreSQL
- Oracle Database
- Microsoft SQL Server
- MariaDB

For example, if your application uses MySQL, MySQL is the DBMS that manages the application's database.

## ⚖️ Database vs DBMS

| Feature | Database | DBMS |
|---|---|---|
| **What it is** | Stores the actual data | Manages the data |
| **Analogy** | Like a storage room | Like the manager |
| **Function** | Contains tables/data | Provides tools to work with the data |

## 💡 Interview answer

If an interviewer asks "What is DBMS?", you can say:

> "DBMS is software used to create, store, retrieve, update, delete, and manage data in a database. It also provides features such as security, access control, concurrency, and backup and recovery."

# Writing and Saving an SQL Script

You can write and save your SQL queries as a script file (with a `.sql` extension) for future use.

## How to Save a Script

In your database tool (like MySQL Workbench):

1. Click on **File** in the top menu.
2. Select **Save Script As...**
3. Choose a location and save it with a descriptive file name.

## How to Run a Saved Script

For future reference, to run that script:

1. Open the saved `.sql` file in your MySQL client (e.g., File > Open SQL Script).
2. Execute the script to run all the saved queries.
